# 🛡️ ネット危険性体験シミュレータ＆見極めクイズ（LINE風）

**「ネットで知り合った人とオフラインで会うことの危険性」**および**「子供のふりをした大人（ネカマ・グルーミング犯）による写真要求・密会誘い出し」**を、親しみやすい**LINE風メッセージUI**の中で安全に疑似体験し、見極める力を養うための**小中学生・保護者向け教育Webアプリケーション**です。

---

## 🎯 開発の背景と教育目的

オンラインゲームやSNS、LINEオープンチャット等の普及により、子どもたちが日常的に見知らぬ人と簡単につながれるようになりました。しかしその裏で、以下のような悪質な犯罪被害が多発しています。

1. **同年代になりすます大人（年齢詐称・ネカマ）**
   - 40〜50代の大人が「小5の女の子」「優しいゲームのお兄さん」「芸能スカウト」を自称して接近。
2. **信頼関係の構築（グルーミング / 手なずけ）**
   - ゲームで助けたり、ギフトをあげて親切に接し、心を開かせる。
3. **周囲からの孤立化と秘密の共有**
   - 「親にLINE見られると怒られるから、二人だけの秘密ね」と言って周囲の大人の目を遮断。
4. **プライベート写真・不適切な写真の要求**
   - 「私も見せたから（※拾い画）」「今の服見せて」「パジャマ姿見せて」「もっと肌が見える写真」と要求がエスカレート。
5. **車での密会誘い出し・連れ去り・脅迫**
   - 「車で公園まで迎えに行くよ」「限定ゲームグッズあげる」「親には内緒ね」と密会へ誘い出し、断ると「写真をネットにばらまくぞ」と脅迫に及ぶ。

本アプリは、こうした**心理誘導プロセスをリアルなLINE風画面の中で安全に疑似体験**し、**「何が危険なのか（レッドフラグ）」「どう断ればいいのか」**を見極められるようになることを目的としています。

---

## ✨ 主な機能

### 1. 💬 LINE風 チャット体験シミュレータ（3つの実践ケース）
- **CASE 1: 「ゲーム友達の女子小学生」の罠（必修・最重要）**
  - 自称・小5女子「あおい🌸」からの放課後LINE（15:20〜15:22...）。写真要求・ギルトトリップ・車での密会誘い出し（正体：48歳無職男性）。
- **CASE 2: 「ゲーム課金をくれる優しいお兄さん」の罠**
  - 親切なお兄さん「レン兄」からの親の不在時間・住所の聞き出しと自宅押し掛け計画（正体：39歳会社員男性）。
- **CASE 3: 「キッズモデル・配信者スカウト」の甘い罠**
  - 公式オーディションを騙る水着写真要求とホテル密室面接詐欺（正体：52歳男性）。

### 2. ❓ 見極めクイズモード（全12問）
- 実際のLINE画面を見て、「何が危険か？」「正しい行動はどれか？」を学ぶインタラクティブクイズ。
- 即時の○×判定・詳しい解説・危険手口名の表示。
- 全問終了後にスコアに応じた**「ネット防犯見極めマスター認定証（S/A/Bランク）」**を発行。

### 3. 📖 危険シグナル図鑑（グルーミング5段階＆レッドフラグ辞典）
- グルーミングの5段階プロセス（ターゲティング ➔ 親密化 ➔ 孤立化 ➔ 境界線破壊 ➔ 犯行・支配）の図解。
- 「親には内緒」「車で迎えに行く」「パジャマの写真」など、出たら100%危険なNGワード集。

### 4. 🆘 ワンタップSOS・相談窓口
- 警察相談専用電話（`#9110`）
- 緊急通報（`110`）
- チャイルドライン（`0120-99-7777`）
- 性犯罪・性暴力被害ワンストップ支援（`#8891`）

### 5. ♿️ 子ども・学校教育に優しい設計
- **美しいフォントと洗練されたLINE風UI**（AI特有の不自然な絵文字を排除し、自然なチャット文体を採用）
- **リアルなタイムスタンプ表示（15:20, 15:22...）** と「既読」演出
- **文字サイズ変更**（標準 / 大 / 特大 切り替え）
- **ふりがな（ルビ）トグル**（低学年でも安心）
- **Web Audio API サウンド**（LINE風ピコン音、危険警告音、正解音、ネタばらし重低音）

## 🚀 起動方法

### 方法 1: Pythonサーバーで起動（推奨）

ターミナルまたはPowerShellで以下を実行します：

```bash
python server.py
```

自動的にブラウザが立ち上がり、`http://localhost:8000/index.html` が表示されます。

### 方法 2: ブラウザで直接開く

`index.html` ファイルをブラウザ（Chrome, Edge, Safari, Firefoxなど）でダブルクリックして開くだけでも完全に動作します（外部通信や依存関係ゼロ）。
